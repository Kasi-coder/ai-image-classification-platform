# Data

The project uses the public **CIFAR-10** dataset.

The dataset is downloaded automatically by `torchvision.datasets.CIFAR10` into the local `data/raw/` directory when training starts.

Classes:

1. airplane
2. automobile
3. bird
4. cat
5. deer
6. dog
7. frog
8. horse
9. ship
10. truck

Official source: https://www.cs.toronto.edu/~kriz/cifar.html
